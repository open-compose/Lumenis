# AS-11 export (Phase 7.2c)

"Media Composer supports the Advanced Media Workflow Association (AMWA) AS-11
specification ... AS-11 is an OP1A MXF file format for the delivery of finished
programming. This specification requires program segment markers" (Editing
Guide p.891-893).

## How it is written

Export As **AS-11** writes the item as MXF OP1a (7.2a, docs/spec/movie-export.md,
the MXF OP1a tab's Video Compression, Audio Format and Bit Depth) into a
temporary file, then bmx's `bmxtranswrap` (BSD-3, `media::bmxTranswrapPath`:
`LUMENIS_BMXTRANSWRAP`, beside the application, or PATH) rewraps it:

```
bmxtranswrap -t as11op1a --mtc --spec-id <shim> --dm-file as11 core.txt
             [--dm-file dpp dpp.txt] --seg seg.txt -o <file> <op1a>
```

FFmpeg writes no descriptive metadata, so without `bmxtranswrap` there is no
AS-11 export; the Console says where to get it (BUILDING.md "AS-11").

## The Export setting's AS-11 tab

* **Shim**: AMWA's AS-11 X1 to X9 (`media::as11Shims`), passed as
  `--spec-id`, its name as the core framework's ShimName. The guide's Shim Set
  button opens Avid's shim files from SupportingFiles (p.892), which are
  Avid's; ours is a menu of the published AMWA shims. The essence must be what
  the shim asks for (X8: XDCAM-50 MPEG-2; X2: AVC-Intra, not offered yet); we
  do not check it.
* **Descriptive metadata** (p.892-893): the AS-11 core framework (Series Title,
  Programme Title, Episode Title Number, Shim Version, Audio Track Layout,
  Primary Audio Language, Closed Captions Present) and, for the UK DPP shims
  (X1, X5, X6), the UK DPP framework's Production Number, Synopsis, Originator,
  Copyright Year, Distributor, Picture Ratio, Completion Date, Contact Email
  and Contact Telephone Number. Empty values are left out
  (`media::as11FrameworkText`); a DPP field bmx requires and we lack makes
  bmxtranswrap fail, with its message in the Console.
* **Segments**: each spanned marker (p.414) within the exported range, in
  order, as "<n>/<count>\t<start> <duration>" (`media::as11SegmentationText`)
  at the export's timecode. No spanned markers: no export.
