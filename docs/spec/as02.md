# AS-02 Export Volumes (Phase 7.2d)

"AS-02 is a specification for grouping multiple versions of program content into
one single bundle ... The basic workflow is to create a new Export Volume Bin,
copy the sequence or sequences you want to the Volume Bin, commit the assets in
the Export Volume Bin, and then archive the AS-02 bundle folder" (Editing Guide
p.901-904).

## The volume (`model::ExportVolume`, `Bin::exportVolume`)

File > New > Volume for Export opens the Export Volume dialog
(`ExportVolumeDialog`): Volume Type (AS-02), Path with Set, a name, the shim
template with Set, and (ours) the Video Compression, J2K by default ("the video
is encoded to the J2K codec", p.904; DNxHR where the build has it, for "DNxHD").
"The Export Volume bin opens" (p.903): an ordinary bin of the volume's name whose
file keeps the volume (`exportVolume` in the bin file), with a bar across its top:
"Export Volume Type, Path to Asset folder, Properties button, Commit button".
Properties opens the same dialog. The asset folder is `<path>/<name>`.

A shim template is read for its ShimName, ShimID and AnnotationText elements
(`model::readShimTemplate`, as AS-02's shim.xml has them); without one,
bmxtranswrap's defaults are used. Avid's own templates in Supporting Files are
not ours; any XML with those elements serves.

## Moving assets

"Select and drag the sequence(s) to the Export Volume. A copy of the sequence(s)
appears in the Export Volume." Other items are refused and named in the Console
("some assets that you selected could not be dragged to the Volume Bin", p.904;
`BinContainer::transferItems`). The copies get the Media Status column, Not
Committed.

## Commit (`MainWindow::commitExportVolume`)

Each sequence not yet committed is exported as MXF OP1a (7.2a) with the volume's
compression, the stereo mix in 24 bits, and rewrapped by bmx's bmxtranswrap
(`media::writeAs02`: `-t as02 --mtc [--shim-name/--shim-id/--shim-annot] -o
<bundle>`) into its own bundle `<asset folder>/<sequence>`, which holds what
p.902 lists (the version's Asset.mxf, the manifest, the shim, the media). "An AAF
copy of the unflattened sequences(s)" goes into the bundle's `extra` folder. The
item becomes Committed. Without bmxtranswrap nothing is committed and the Console
says why (BUILDING.md "AS-11 and AS-02").

Ours: one bundle per sequence, so two versions do not share their video essence
yet (p.901's English and Spanish mixes); Media Status as text, not the guide's
green, yellow and red; Offline not shown.
