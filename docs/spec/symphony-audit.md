# Symphony Option items in the guides (8.7d)

Media Composer's guides mark features of the Symphony Option "(Symphony Option)" or "(Media Composer | Symphony
Option)". We build one product, so each is either built, planned or decided against. The audit (2026-11-10) went
through every mention in the 2025.12 Editing Guide (36 lines) and FX Guide (216).

## FX Guide

Every Symphony mention is colour correction: relationship corrections and the Correction Type menu, the Luma Ranges
and Levels and Secondary groups, Channel Blending, the Tab buttons, Automatic Effect Templates, the Timeline's colour
correction display and indicator lines, Managing Color-Corrected Sequences, shape-based correction, Spot Color
Correction, NaturalMatch and the Color Match control, the Correction settings marked Symphony. All are built (6.10a to
6.10e). Avid Artist Color's controls (ch.25, p.744 on) wait for that control surface hook (EXTENSIONS.md).
