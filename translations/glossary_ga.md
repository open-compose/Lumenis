# Cutthulhu — Irish (ga) glossary (draft for native review)

Standard: An Caighdeán Oifigiúil. Sources: **téarma** = téarma.ie; **loc** = Irish
software localisations (GNOME / LibreOffice / Mozilla / Microsoft Irish);
**bcast** = TG4 / RTÉ usage; **coined** = no established term found, a plain
descriptive term made for Cutthulhu, to be checked by the reviewer.

Register: menu commands and buttons are imperatives, 2nd person singular
("Sábháil", "Oscail", "Scrios"); window and setting names are nouns; sentence case.
Gender / genitive shown as (f., gen.) where it drives mutations.
